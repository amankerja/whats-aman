WhatsApp Local Hub
Codename: WAHub

Status: Product Definition

============================================================
1. PRODUCT VISION
============================================================

WhatsApp Local Hub adalah aplikasi desktop/portable local-first
untuk mengelola satu atau beberapa akun WhatsApp dari satu
dashboard.

Konsep produk menggabungkan:
- Baileys: WhatsApp connectivity/core engine
- WAHA: API, session management, webhook, OpenAPI concepts
- OpenWA: automation dan utility concepts

Ketiga proyek tidak dijalankan sebagai tiga server terpisah.
Produk menggunakan satu Application Core dengan Baileys sebagai
WhatsApp engine.

Arsitektur tingkat tinggi:

Desktop UI
    |
    v
Application Core
    |
    +--> Session Manager
    +--> Message Service
    +--> Contact Service
    +--> Campaign Engine
    +--> Automation Engine
    +--> Webhook/Event Bus
    +--> REST API
    |
    +--> Baileys Engine
    |
    +--> SQLite
    |
    v
WhatsApp

- Jangan menjalankan ketiga project sebagai tiga backend terpisah.
- Kompatibilitas protokol WhatsApp dapat berubah sehingga adapter
  harus dibuat modular dan mudah diperbarui.

3. PROBLEM STATEMENT
============================================================

Pengguna yang ingin menjalankan sistem WhatsApp automation sering
harus menggabungkan WhatsApp engine, database, API, webhook,
dashboard, automation, session manager, dan server.

Hal tersebut membuat instalasi dan maintenance menjadi rumit.

WhatsApp Local Hub bertujuan menyatukan komponen tersebut menjadi
satu aplikasi lokal yang mudah dijalankan.

Target pengalaman:

Download -> Extract/Install -> Run -> Scan QR -> Ready

Basic installation tidak membutuhkan:
- Docker
- MySQL
- PostgreSQL
- Redis
- Node.js manual
- konfigurasi server manual

untuk pengguna akhir.

============================================================
6. NON-GOALS
============================================================

Versi awal tidak bertujuan menjadi:
- WhatsApp resmi Meta API replacement
- Cloud WhatsApp hosting
- CRM enterprise penuh
- Cloud marketing platform
- Mass-spam tool
- Tool untuk menghindari sistem anti-abuse WhatsApp

Campaign dan automation wajib memiliki operational safeguards
seperti:
- Rate limit
- Quota
- Opt-out
- Suppression list
- Audit log

Safeguard digunakan untuk operational control dan responsible
messaging, bukan untuk menghindari sistem anti-spam.

34. SECURITY REQUIREMENTS
============================================================

SR-01 Session Isolation
Session tidak boleh mengakses authentication data session lain.

SR-02 API Authentication
API write operations membutuhkan authentication.

SR-03 Secret Protection
API keys dan authentication material tidak disimpan plaintext jika
tidak diperlukan.

SR-04 Local Binding
Default API hanya bind ke 127.0.0.1.

SR-05 Audit
Perubahan penting harus dicatat.

Contoh:
- Session created
- Session deleted
- API key created
- Campaign started
- Campaign stopped
- Automation modified
- Backup restored

SR-06 Sensitive Logging
Nomor telepon, token, auth material, dan isi pesan tidak boleh
masuk log secara berlebihan.
